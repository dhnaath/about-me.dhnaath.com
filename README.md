# Dhnaath Portfolio

Website portfolio, resume, cover letter, dan personality traits — [aboutme.dhnaath.com](https://aboutme.dhnaath.com).

Front-end saja: React 19 + Vite + Tailwind CSS 4 + TypeScript.

## Menjalankan

```bash
npm install
npm run dev        # http://localhost:5173
```

## Build produksi

```bash
npm run lint       # cek tipe TypeScript
npm run build      # hasil di folder dist/
npm run preview    # uji hasil build secara lokal
```

Folder `dist/` adalah situs statis dan bisa di-deploy ke hosting statis mana pun
(Vercel, Netlify, Cloudflare Pages, GitHub Pages, dll.).
